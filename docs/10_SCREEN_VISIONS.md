# Purpose

This document defines the vision for every major screen within BinderHaven.

Unlike the Design System, which establishes universal design rules, this document focuses on individual experiences.

Every screen should answer three questions:

• Why does it exist?

• What should the collector accomplish?

• How should it make the collector feel?

Every future screen should be documented here before implementation begins.

---

# Screen Design Principles

Every screen should satisfy the following goals.

## Collector First

The collection is always the focus.

---

## Beautiful by Default

Even an empty collection should feel premium.

---

## Information Without Clutter

Only display information that helps the collector.

---

## Progress is Motivation

Completion should remain visible.

Collectors should always know how close they are.

---

## Customization Creates Ownership

Collectors should feel like BinderHaven belongs to them.

# Library

Status

In Design

Purpose

The collector's home.

Every binder owned by the collector is displayed here.

This is the screen collectors will spend the most time viewing.

User Goal

Browse collections.

Choose a binder.

Admire the collection.

Emotional Goal

Ownership.

Pride.

Motivation.

Layout (Current Direction)

• Two binder covers per row.

• Vertical scrolling.

• Large binder covers.

• Premium spacing.

• Custom wallpaper background.

• Clean navigation.

Each binder should immediately communicate:

• Collection

• Completion %

• Cards Owned

• Cards Remaining

Collectors should understand the state of a collection without opening it.

Customization

Future support includes:

• Wallpaper selection

• Binder themes

• Favorites

• Sorting

• Filtering

Future layouts may be introduced without replacing the default experience.

Empty State

Celebrate the beginning of a collection.

Invite collectors to create their first binder.

Never feel unfinished.

Loading State

Skeleton placeholders.

Subtle fade animations.

Error State

Friendly messaging.

Retry option.

Acceptance Criteria

The Library should feel like opening a premium personal collection.
